# 16x1 Multiplexer in Verilog

## Overview
This project implements a 16x1 multiplexer using Verilog HDL and verifies its functionality using an exhaustive testbench.

## Features
- 16 data inputs and 1 output.
- 4-bit select line.
- Exhaustive functional testing.
- File reading and writing using Verilog system tasks.

## Project Files
- `16X1_mux.v` – Verilog design of the 16x1 multiplexer.
- `16X1_tb_mux.v` – Exhaustive testbench.
- `input.txt` – Input test patterns.
- `.gitignore` – Excludes generated simulation files.

## Tools Used
- Verilog HDL
- Icarus Verilog
- GTKWave

## Verification
The testbench applies input patterns, reads test data from a file, and records simulation results in an output file.
